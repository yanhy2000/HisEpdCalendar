# 开发指南

面向想改代码 / 换机型适配 / 自建服务端的开发者。安装使用请看
[社区部署与卸载指南](社区部署与卸载指南.md)。

## 1. 项目组成

| 部分 | 位置 | 说明 |
|---|---|---|
| 控制台 App | `epdcalendar-app/src/com/hi/epdcalendar/` | 刷新流水线、定时计划、渲染宿主、su 落位、控制台 UI |
| Xposed hook | `epdcalendar-app/src/com/hi/epdclock/` | 与 App 同 APK；装载进锁屏引擎与 system_server，**不得引用 App 的类** |
| Xposed API 桩 | `epdcalendar-app/xposed-stubs/` | 仅编译期 classpath，不进 dex；运行时由框架提供 |
| 渲染模板 | `epdcalendar-app/assets/template/landscape.html` | WebView 渲染 960×540 CSS，@2x 输出 1920×1080 |
| 构建工具 | `tools/` | build.py（构建/部署）、render_preview.py（模板预览）、patch_installer_v4.py 等 |

## 2. 构建环境

依赖：JDK 8+（javac/jar/jarsigner/java）、Python 3.10+、adb、Playwright+Pillow（仅预览用）。

工具链文件（约 53MB，不入库，放到 `tools/android-sdk/` 与 `tools/apktool-bin/`）：

```text
tools/android-sdk/android-25.jar   # Sable/android-platforms 仓库 android-25/android.jar
tools/android-sdk/r8.jar           # maven.google.com → com.android.tools:r8 任一 8.x
tools/apktool-bin/aapt2_64.exe     # 从 apktool.jar 内 prebuilt/windows/aapt2_64.exe 抽取
                                   # （apktool 自带的 aapt2 在部分机器 NPE，抽出的独立版可用）
```

签名密钥（首次需要自建，**严禁入库**）：

```bash
keytool -genkeypair -keystore xposed-sign.keystore -alias xposed \
    -keyalg RSA -keysize 2048 -validity 10000
```

## 3. 构建 / 部署

```bash
python tools/build.py              # 仅构建 → epdcalendar-app/build/epdcalendar-signed.apk
python tools/build.py --install    # 构建 + 安装 + 补权限/Doze 白名单
python tools/build.py --deploy     # install + modules.list 同步 + 重启验证
```

密钥通过环境变量提供（也可把 keystore 放仓库根目录按默认名）：

```bash
set EPD_KEYSTORE=D:\path\to\xposed-sign.keystore
set EPD_KEYSTORE_PASS=你的密码
```

构建链：javac(桩) → javac(主源码) → D8 → aapt2 link → 注入 classes.dex →
jarsigner 签名。Xposed API 桩绝不进 dex（`--classpath` 仅供编译期解析）。

## 4. 模板开发

```bash
python tools/render_preview.py                    # 用 tmp/render_input.json（真机抓的云端数据）
python tools/render_preview.py docs/api-data-sample.json   # 用契约样例，离线开发
```

渲染管线与手机一致：960×540 CSS @2x → 1920×1080 → 顺时针转 90° → 1080×1920。
输出 `tmp/preview_land.png`（横版）与 `tmp/preview_portrait.png`（手机视角）。

模板要点：

- 数据由 `window.INKSYNC_DATA` 注入；天气图标经 `window.ICON_DATA`（base64 SVG）
  内嵌——`loadDataWithBaseURL` 的内容页禁止 file:// 子资源
- **右上时间槽与右下电池槽的坐标不可动**：hook 每分钟在固定坐标白槽擦除后重画
  实时值（竖屏画布 pivot(493,842) 顺时针 rotate 90° 绘制，横屏→竖屏换算
  `rx=lx-349, ry=ly+796`）
- 月历用 CSS grid 顺序排格，**必须用 `calendar.adjusted_first_day` 补月初空位**，
  否则 1 号被顶到第一列、星期错位
- 6 行月历自动切 `dense` 模式缩小字号

## 5. hook 开发注意（API 25）

- smali/低版本 API 陷阱：`Paint.setStyle` 在 API25 返回 **void**（新版为链式），
  反编译参考或手写签名时务必对照旧版 API
- hook 类自包含（只用 android.* + Xposed API），不依赖 App 类与任何资源
- 所有 hook 外层 try/catch + `XposedBridge.log`，任何异常回退原方法行为
  （最坏情况 = 原厂画面，不会崩宿主进程）
- 模块开关（`.calendar_off` / `.quiet` 标志文件）每次 hook 调用时检查，免重启切换

## 6. 服务端契约

App 只依赖一个 HTTP 接口：

```text
GET {server}/api/data
Header: X-API-Key: <token>
→ JSON：{ system_info, weather, hitokoto, calendar }
```

完整字段与样例见 [api-data-sample.json](api-data-sample.json)。要点：

- `weather.icon` / `forecast[].dayicon` 为和风风格代码字符串，App assets 内置
  38 个对应 SVG
- `calendar.adjusted_first_day` 为月初空位数（模板必用）
- `system_info.battery` 由手机端注入，不是服务端字段
- 建议服务端做 X-API-Key 鉴权 + 限速 + 天气缓存（保护高德每日额度）

## 7. 关键逆向事实（换机型适配参考）

- 原厂管线：`EInkLockScreenEngine`（锁屏进程，persistent，分钟闹钟）读
  `/sdcard/eink_clock/eink_lockscreen_wallpaper.png` → `EpdManagerService`
  （system_server）上屏 → `BottomBarController` 盖章解锁条/电池
- 壁纸 1080×1920 = 横版 960×540 顺时针转 90°（横握听筒朝左时正立）
- 引擎守门设置（Settings）：`secure eink_wallpaper_index`（-1=自定义/0=原厂内置）、
  `global lock_to_wallpaper`、`global lockscreen_time_style=2`（保活分钟循环）
- 解锁手势在触摸驱动层，与绘制 hook 无关
- HMCT ROM 特性：`install -r` 更换应用目录（modules.list 需同步）；modules.list
  的读取者是 `xposed_zygote_service`（untrusted_app 域带类别标签），**不要用
  root 在安装器数据目录手工建目录/文件**（会丢类别标签挡住读取）；
  第三方 app 无 sdcard_rw 组，写 /sdcard 走 su 落位
