# 社区部署与卸载指南

> 适用：海信 A2 Pro（Hisense A2T，Android 7.1.2）改造墨水屏桌面日历。
> 前提：手机已解锁 BL 并装好 Magisk（有 root）。本文不含 BL 解锁/Magisk/adb 等环境安装。
> 安装器使用补丁版（与官方原版的差异见 `docs/补丁版安装器说明.md`）。
> 实测更新：2026-08-22（模块开关原生可用，无需任何手工修复 modules.list）。
> **本指南提到的 4 个文件均在本仓库 GitHub Releases 下载。**

## 一、所需文件（4 个）

| 文件 | 说明 |
|---|---|
| `[面具模块]Xposed框架-systemless-sdk25-arm64.zip` | Xposed v89 框架（systemless，Magisk 模块形式） |
| `[安装器-补丁版]XposedInstaller_v4-signed.apk` | Xposed 安装器（管理模块/看日志） |
| `[墨水屏模块]墨水日历v2.0-App与Hook一体.apk` | 日历 App + Xposed hook 合并包 |
| `[配套文件]推送到sdcard改名为xx.txt` | 可选，让安装器状态页正确显示框架版本 |

## 二、安装流程（按顺序，全程手机操作，仅可选项需电脑）

1. **拷文件**：电脑通过 MTP/文件传输把上面 4 个文件拷到手机 `Download` 文件夹
2. **刷框架**：打开 Magisk App → 模块 → 从存储安装 → 选择 `[面具模块]...zip` → 完成后**重启**
3. **装安装器**：用文件管理器安装 `[安装器-补丁版]` APK，**打开它一次再退出**
   （这一步会自动创建配置/日志目录，**不能省**，否则模块清单读写异常）
4. **（可选）让状态页显示"已安装 v89"**：
   - 系统设置 → 应用 → Xposed Installer → 权限 → 打开「存储」
   - 把 `[配套文件]...xx.txt` 改名为 `xx`，移动到内部存储**根目录**（即 /sdcard/）
   - 此步仅影响主页状态显示，跳过不影响任何功能
5. **装日历**：安装 `[墨水屏模块]` APK
6. **启用模块**：打开 Xposed Installer → 模块页 → 勾选「墨水日历」→ 按提示**重启**
7. **配置**：打开「墨水日历」App：
   - 允许存储权限（弹窗）
   - 填服务器地址 / API 密钥 / 刷新正则（不懂正则就用默认的每 3 小时整点）
   - 保存 → 打开「桌面日历模式」开关 → Magisk 弹出 root 授权 → **允许** → 自动进行首次刷新
8. **完成**：等下一次分钟跳变，墨水屏显示完整日历 + 右上实时时钟 + 右下电池

### 日常使用要点

- **模块的启用/禁用都需要重启生效**（模块代码在进程启动时装载）
- 只想暂停日历显示：墨水日历 App 里关闭「桌面日历模式」，一分钟内回原厂锁屏，无需重启
- 安装器主页 "Could not load available ZIP files" 提示 = 官方下载服务器 2021 年关站，无视
- 安装器「下载」页已失效，框架只能靠 zip 刷入
- 长期收纳：控制台「刷白墨水屏」→ 白屏后关机

## 三、卸载方法（按顺序，尽量无残留）

1. **还原锁屏**：墨水日历 App → 关闭「桌面日历模式」（自动把壁纸设置还原为原厂）
   - 若 App 已无法打开，用电脑执行：`adb shell settings put secure eink_wallpaper_index 0`
2. **取消模块**：Xposed Installer → 模块页 → 取消勾选「墨水日历」（不重启，继续下一步）
3. **卸载日历 App**：正常卸载「墨水日历」
4. **卸载安装器**：正常卸载「Xposed Installer」（其数据目录连同 modules.list 一并删除）
5. **移除框架**：Magisk App → 模块 → Xposed Framework → 移除（垃圾箱图标）→ **重启**
   （重启后所有 hook 消失；/sbin/xposed.prop 在内存盘上，自动消失）
6. **清理文件**：文件管理器删除内部存储根目录的 `xx` 文件和 `eink_clock` 文件夹
7. **完成**：锁屏回到原厂样式。BL 解锁、Magisk、root 全部不受影响

### 残留说明

- 正常按上述流程操作，卸载后无残留：modules.list 由安装器 App 自建自写，
  卸载时随应用数据目录整体清除
- 极少数情况下 Xposed Installer 卸载后 `/data/user_de/0/de.robv.android.xposed.installer`
  目录残留（多见于曾经用 root 手工写过该目录内文件）：重装一次安装器再卸载即可；
  或 `adb shell "su -c 'rm -rf /data/user_de/0/de.robv.android.xposed.installer'"`
